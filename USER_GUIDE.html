1. 软件简介

AI File Renamer 是一款 Windows 桌面应用，它使用云端 AI（DeepSeek、OpenAI 或 Claude）来读取文件的实际内容，然后自动生成描述性的文件名。

🔍 智能重命名

AI 阅读 PDF、Word、Excel、PPT、TXT、图片等文件内容，提取关键信息生成文件名。

📋 批量处理

一次扫描整个文件夹，预览所有 AI 建议，确认后一键批量重命名。

↩ 一键撤销

每次重命名操作都记录在案，随时可以撤销恢复到原始文件名。

🔒 隐私安全

API Key 和配置文件都存储在本地。你的 API Key 不会被分享给第三方。

🎨 命名模板

自定义文件名格式：日期、标题、标签、类型等变量自由组合。

👁 文件夹监控

设定监控目录，新文件出现时自动 AI 处理，无需手动操作。

3. 配置 AI API Key

首次使用需要配置 AI 服务商的 API Key。推荐使用 DeepSeek（价格实惠，注册即送免费额度）。

获取 API Key

🔵 DeepSeek 推荐

访问 platform.deepseek.com → 注册 → API Keys → 创建 Key

模型：deepseek-v4-pro（高质量）或 deepseek-v4-flash（快速便宜）

🟢 OpenAI

访问 platform.openai.com → API Keys → 创建 Key

模型：gpt-4o 或 gpt-4o-mini

🟠 Claude

访问 console.anthropic.com → API Keys → 创建 Key

模型：claude-sonnet-4-20250514

在软件中配置

  1. 启动软件，点击工具栏 ⚙ 设置
  2. 切换到 AI 服务商 标签页
  3. 选择服务商（如 DeepSeek）
  4. 粘贴 API Key
  5. 选择模型（下拉菜单会自动显示该服务商的可用模型）
  6. 点击 🔗 测试连接 确认配置正确
  7. 看到 "连接成功" 提示后，点击 OK 保存
💡 提示：如果测试连接失败，软件会自动尝试添加 /v1 后缀。DeepSeek 用户请确保模型名是 deepseek-v4-pro 或 deepseek-v4-flash（旧的 deepseek-chat 已废弃）。

4. 快速上手

基本操作流程

  1. 添加文件
    点击 📁 添加文件夹 选择要处理的文件夹，或点击 📄 添加文件 选择单个文件。
    建议先用少量文件测试，确认效果后再处理大量文件。
  2. AI 分析
    点击 🔍 扫描并AI分析，软件将依次：
    • 扫描所有文件
    • 提取文本内容和元数据
    • 调用 AI 生成结构化信息
    • 按模板拼出建议的文件名
    进度条会显示当前处理状态。
  3. 预览与编辑
    在表格中查看 AI 建议的文件名：
    • 双击建议文件名可直接编辑
    • 状态列显示：✅ 建议成功 / ❌ 失败（可查看失败原因）
    • 红色高亮表示文件名冲突
  4. 应用重命名
    确认无误后点击 ✅ 应用重命名，确认对话框后将执行批量重命名。
    所有操作记录保存在 rename_history/ 目录。
  5. 撤销（如需要）
    如需恢复，点击 ↩ 撤销上次，按批次反序还原所有文件名。
⚠️ 重要：首次使用请先在测试文件夹上试验。重命名操作会直接修改磁盘上的文件名，虽然支持撤销，但建议先确认 AI 建议符合预期再应用。

5. 命名模板系统

命名模板决定了 AI 的分析结果如何组装成最终文件名。AI 负责"理解文件内容"，模板负责"控制输出格式"。

内置模板

默认模板格式：{date}_{title}.{ext}

例如 AI 分析出一份文件的日期是 2025-07-26、标题是"季度销售报告"，最终文件名为：2025-07-26_季度销售报告.pdf

可用变量

变量说明来源
{date}文件日期AI 从内容中提取
{title}文件标题AI 从内容中提取
{type}文件类型/分类AI 从内容中判断
{tags}关键词标签AI 从内容中提取
{language}语言AI 从内容中识别
{ext}原文件扩展名系统自动获取
{original_name}原始文件名系统自动获取
{file_type}文件格式系统自动获取

自定义模板

在菜单栏选择 工具 → 模板管理：

  1. 点击 新建 创建模板
  2. 命名模板（如"会议记录模板"）
  3. 编写格式模式（如 {date}_{type}_{title}.{ext}）
  4. 选择分隔符（_、-、空格等）
  5. 选择日期格式（YYYY-MM-DD / YYYYMMDD / YYYY-MM 等）
  6. 查看实时预览确认效果
  7. 点击 💾 保存模板

模板示例

场景模板效果示例
默认{date}_{title}.{ext}2025-07-26_季度报告.pdf
带分类{type}/{date}_{title}.{ext}报告/2025-07-26_季度报告.pdf
带标签{date}_{tags}_{title}.{ext}2025-07-26_重要_销售_季度报告.pdf
短格式{date}_{title}.{ext}20250726_季度报告.pdf
保留原名{date}_{title}_{original_name}.{ext}2025-07-26_报告_原始文件名.pdf

6. 文件夹监控

文件夹监控功能可以让你"设置一次，永远自动处理"。适合持续产生文件的场景（下载文件夹、扫描文件夹、项目文件夹等）。

设置监控

  1. 点击工具栏的 👁 监控 切换到监控视图
  2. 点击 ➕ 添加监控
  3. 选择要监控的文件夹
  4. 选择处理模式：
    • 先审阅再重命名 — 检测到新文件后在重命名视图中提示（推荐）
    • 自动重命名 — 检测到新文件后全自动处理（无需人工干预）
  5. 勾选"包含子文件夹"可递归监控
  6. 点击 OK
📌 工作原理：监控使用文件系统事件检测新文件。当文件写入完成（大小稳定 2 秒后），自动触发 AI 分析。在"自动重命名"模式下，整个过程无需任何点击。

7. 自动归类

重命名后，软件可以自动将文件移动到分类好的子文件夹中。

归类规则

规则效果示例
按日期按年月分文件夹2025/07/文件名.pdf
按文件类型按 AI 识别的文档类型分报告/文件名.pdf、合同/文件名.pdf
按分类按 AI 标签的首个关键词分销售/文件名.pdf
按项目按 AI 识别的项目名分XX项目/文件名.pdf

启用归类

  1. 打开 ⚙ 设置 → 文件整理
  2. 勾选"重命名后自动归类文件"
  3. 选择归类规则
  4. 选择目标文件夹（即归类的根目录）
  5. 保存

9. 常见问题

Q: 测试连接失败怎么办？

A: 依次检查：

  1. API Key 是否正确（注意不要有多余空格）
  2. 网络是否正常（能否访问 api.deepseek.com）
  3. 模型名是否正确（DeepSeek 请用 deepseek-v4-pro）
  4. 软件会自动尝试带 /v1 的 URL
  5. 查看 logs/ 目录中的日志文件获取详细错误

Q: 重命名后能撤销吗？

A: 可以。所有重命名操作记录在 rename_history/ 目录的 JSONL 文件中。点击 ↩ 撤销上次 按批次反序恢复。如果软件关闭后需要撤销，可以重新打开并点击撤销（只要历史文件还在）。

Q: AI 分析结果不理想怎么办？

A: 有几个办法：

  • 双击表格中的建议文件名直接手动修改
  • 在设置中调整"系统提示词"，让 AI 按你的偏好工作
  • 自定义命名模板，控制输出格式
  • 每个文件都可以在应用前手动编辑最终文件名

Q: 处理大文件会消耗很多 API 额度吗？

A: 不会。软件默认只发送前 4000 个字符给 AI（可在设置中调整），不会把整个文件上传。一个大文件的实际 API 消耗大约 1000-2000 tokens。以 DeepSeek 的价格（约 0.001 元/1K tokens），处理一个文件只需几分钱。

Q: 文件名冲突了怎么办？

A: 软件会自动检测同名冲突。冲突的文件名会追加 _1、_2 等后缀。表格中冲突的文件会以红色高亮显示。

Q: 支持其他 AI 服务商吗？

A: 支持！目前内置了 DeepSeek、OpenAI、Claude 三个服务商。设置中选择即可切换。只要是 OpenAI 兼容的 API（如 Ollama、vLLM、硅基流动等），也可以通过修改 Base URL 来接入。

Q: 文件重命名后还能组织到子文件夹吗？

A: 可以。在设置的"文件整理"标签页中启用自动归类，选择规则（按日期/类型/分类/项目）和目标根目录即可。
