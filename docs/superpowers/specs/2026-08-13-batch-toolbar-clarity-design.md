# Batch 顶部工具栏中文清晰化设计

日期：2026-08-13
状态：方案 A 已获 Product Owner 口头批准，待书面规格复核

## 目标

让 Batch 页顶部工具栏无需悬停解释即可理解，消除中英文混用、含糊缩写、重复说明和悬停弹层造成的干扰，同时保持 1000×700 参考窗口与 900×640 最小窗口下的单行布局。

## 设计原则

1. 中文界面优先使用完整、直接的中文动作名称。
2. 已经写明用途的文字按钮不再显示 Tooltip。
3. Tooltip 仅用于没有文字标签的纯图标按钮，并延迟约 500 毫秒显示中文解释。
4. ComboBox 只允许点击后展开；鼠标悬停不能打开选项、不能显示重复选项或第二行解释。
5. 保持蓝本的单行工具栏结构，不新增固定说明区、不把常用操作藏进多级菜单。

## 控件与行为

### 模板选择器

- 中文界面显示本地化名称“通用命名（默认）”。
- 默认模板的领域标识和公式保持不变；只本地化面向用户的显示名称。
- 单击选择器才展开选项列表。
- 悬停不得展开列表，也不得出现与当前值相同的第二行文本。
- 列表出现时必须是明确的下拉浮层，并具有选中态。

### 导入与目标目录

- 三个按钮完整显示“添加文件”“添加文件夹”“目标目录”。
- 文字按钮不显示 Tooltip。
- 选择目标目录后，按钮显示“已选目标目录”；具体路径不挤进按钮，可在点击后重新选择，任务卡和执行逻辑保持不变。

### 搜索与状态筛选

- 搜索框保持“搜索文件名…”占位文案。
- 状态筛选默认显示“全部状态”，点击后列出既有九种状态。
- 悬停不弹出解释或选项。

### 批量操作

- 有足够空间时显示“应用所选”“停止任务”“清空工作区”。
- “应用所选”继续仅在至少选中一个任务时可用。
- 900px 宽度不足时，右侧批量操作允许采用蓝本式纯图标按钮；图标按钮必须提供延迟中文 Tooltip 和 Accessible.name。
- “添加文件”“添加文件夹”“目标目录”在 900px 下仍不得缩写成“文件”“文件夹”“目标”。

## 响应式布局

- 1000×700：全部操作使用完整中文文字，保持单行。
- 900×640：模板、导入、目标目录、搜索和状态筛选保持可见；优先压缩搜索框宽度，再把右侧批量操作切为图标。
- 不允许控件重叠、文字裁切、工具栏换行或隐藏关键动作。
- 下拉浮层不得超出窗口边界或被工作区裁切。

## 国际化与数据迁移

- 新增或调整的可见文案全部进入 `zh_CN.json` 与 `en_US.json`。
- 新建默认模板使用稳定的领域标识；显示名称按当前语言计算。
- 已经存在于用户数据中的英文默认模板名称，不要求破坏性改写存储文件；UI 对已识别的内置默认模板按当前 locale 显示本地化名称。
- 用户自建模板名称保持原样，不自动翻译。

## 测试与视觉验收

自动化测试必须覆盖：

1. 中文和英文文案完整性。
2. 默认模板中文显示与英文切换。
3. 文字按钮不存在 Tooltip。
4. ComboBox 悬停不展开、点击才展开。
5. 1000×700 与 900×640 下关键控件均可见且互不重叠。
6. 900px 下右侧批量操作的响应式图标与 Accessible.name。
7. 现有选择、搜索、筛选、导入、目标目录和批量动作接线不回归。

Codex 原生 Windows 验收必须覆盖：

1. 真实鼠标依次悬停所有文字按钮，确认不出现解释浮层。
2. 悬停模板和状态筛选器，确认不展开；真实点击后才展开。
3. 中文字体可读，不出现 tofu 方框、英文默认模板或文字裁切。
4. 1000×700、900×640 两种窗口尺寸无重叠、遮挡或越界。
5. 对照私有蓝本证据，确认工具栏仍为简洁单行结构。

截图仅写入 `tests/screenshots/qa-current/`；未经另行批准不更新正式 Golden。

## 非目标

- 不修改 Batch 任务状态机、文件导入、AI 分析、Apply/Undo 或 Watch 逻辑。
- 不重新设计左侧导航、任务卡和空态主体。
- 不新增多级“添加内容”菜单。
- 不把所有文字按钮改为图标，也不依赖 Tooltip 解释常用操作。
