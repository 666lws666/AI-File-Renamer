## 结论与使用入口

已完成本轮清单：真实 Windows EXE 的 Batch/Watch Apply/Undo、扫描 PDF、视频关键帧命名；本地 fast-forward 合并、主目录重建与回归；快捷方式备份和读回核验。当前产物适合先在文件副本上试用，不等于所有文件、硬件或云端服务均已验证，也不是“零 bug”保证。

本机可以点击仓库主目录的「序匣」快捷方式；其目标是 `dist/Xuxia/Xuxia.exe`，工作目录是完整产物目录，没有诊断参数。不要只复制 EXE 而丢掉 `_internal` 和手册资源。

第一次使用本地模式：

1. 选择「本地隐私」，在设置中打开本地资源管理。
2. 离线导入时选择 `dist/本地模型离线资源/资源/`；该包的「先读我.txt」有操作说明、固定大小和哈希。它是已验证公共资源的副本，不是自动启用的用户配置。
3. 等待校验及模型自检成功，再添加文件。取消或失败不会自动切回云端。
4. 选择文件名输出语言，以及「AI 智能命名」或「按模板命名」。先核对建议，再应用；需要恢复时撤销。Watch 初次试用建议选「先审核」。

完整简体中文、繁体中文（香港）和英文 HTML 手册已随程序分发，三个文件及整个资源树与主目录源码逐字节一致。用户无需安装 Python 或自行启动模型服务。

## 本轮真实缺陷与修复

1. 诊断按终态过早调用 Undo：进度已发布时，Apply 所有者仍有完成回调尾部。先写延迟完成负测，再等待原有 Batch pending=false / Watch workers_idle 边界；不修改生产执行器的安全条件。
2. 标题模板指令没有清楚要求内容概括；实际 Qwen 返回 understood=true 但 dcTitle=null。最初单纯解释标题仍未解决。经保留原始输出、严格对照的提示词实验定位到无关空日期/版本块和尾部顺序，再用通用的请求字段组合修正及五语言回归。没有强造标题、变更 schema、允许无依据字段或用固定样本答案过关。
3. 扫描 PDF 的实际模型返回有依据的完整英文月份 `October 2026`，但旧日期证据解析仅支持数字/中文，错误拒绝为 INVALID_RESPONSE。补完整英文月份的严格日期与精度测试，拒绝无效日期和降级猜测，保留 JSON/证据校验；真实原样响应及新 EXE 都验证通过。
